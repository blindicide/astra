# ASTRA

ASTRA is a C++20 nixpkgs-backed application package manager under development. The current build is **0.3.0-dev**: CLI, private SQLite state, pinned revision indexing, cached search/info, and per-user managed profile transactions. Install, remove, upgrade, update, and rollback are exercised with a disposable fake Nix backend; live Nix integration is unverified. Commands that have no implementation fail explicitly.

ASTRA owns repository policy, transaction records, and managed profiles; Nix is intended to own evaluation, builds, the store, binary substitution, and supported profile operations. No Almagest-G native build or Nix integration has been validated here. See [MILESTONES.md](MILESTONES.md) for acceptance evidence.

Build locally with `make -j2` and run `make check`. No build step downloads dependencies. See [BUILDING.md](BUILDING.md).

After a live Nix backend is validated, use `astra update` to refresh the approved pinned revision without changing installed packages, then review `astra install hello jq`. Interactive use asks for confirmation; `--yes` accepts the plan but source builds still require `--allow-build`. ASTRA tries the official signed cache before considering a consented local build. `astra list`, `astra why NAME`, `astra history`, `astra history show ID`, `astra upgrade`, and `astra rollback` operate on ASTRA's own `default` profile. `why` reports direct selections or paths in their locally queried Nix runtime closures. Choose another per-user profile with `--profile NAME`. `astra verify` checks SQLite integrity and reconciles and audits every recorded user profile; it can complete a prepared transaction after an interrupted activation. `astra --dry-run clean` lists abandoned ASTRA links; `astra --yes clean` removes only those links and retains all recorded generations. `astra --dry-run repair` reports missing committed GC roots and prepared transactions; confirmed `repair` restores validated missing roots and reconciles prepared work. The managed executable path is `$XDG_STATE_HOME/astra/profiles/NAME/profile/bin` (or `$HOME/.local/state/astra/profiles/NAME/profile/bin` when XDG_STATE_HOME is unset); add it to your shell PATH explicitly if desired. ASTRA does not alter your existing Nix profiles or shell configuration.
